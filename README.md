# Ruslan True — презентация

Публичный адрес открывает только интерактивную HTML-презентацию из пяти слайдов. Рабочий лендинг и его форма не публикуются. Исходники прежней версии сохранены в истории Git и в локальной резервной копии.

## Запуск

```bash
python3 -m http.server 3000 --directory dist
```

Откройте http://localhost:3000. Навигация: кнопки, точки и клавиши ← / →.

На третьем слайде доступны календарь и демо-запись. На четвертом — симуляция блокировки слота и макет уведомления. Данные хранятся только в памяти страницы. Реальные записи не создаются и сообщения не отправляются.

Скриншоты показывают интерфейс проекта. Ссылок для перехода к рабочему сайту нет. Шрифты Google Fonts и иконки FontAwesome загружаются через интернет.

Каталог публикации Render: dist. Старая ссылка /presentation/ перенаправляет к презентации на главной странице.
