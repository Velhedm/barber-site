# Изолированная проверка iPhone до публикации

Подготовлен отдельный запуск `node scripts/preview-server.js`. Он не запускает
боевой `server/index.js` и принудительно использует SQLite в оперативной памяти,
даже если в окружении случайно задан `DATABASE_URL`. Данные сбрасываются при
перезапуске. Создаётся одна условная услуга и один условный мастер исключительно
для теста; обе страницы содержат надпись TEST / SINAQ / ТЕСТ. Клиентские Email и
восстановление пароля принудительно отключены; настоящие данные не вводить.

Для проверки требуются отдельный HTTPS-адрес, на котором можно временно запустить
этот процесс, и переменные `ILKER_PREVIEW_ORIGIN`, `ILKER_PREVIEW_PASSWORD` (не
менее 24 символов), `ILKER_PREVIEW_VAPID_SUBJECT`, `ILKER_PREVIEW_VAPID_PUBLIC`,
`ILKER_PREVIEW_VAPID_PRIVATE`. Адреса действующего сайта запрещены. Используйте
новый пароль и новые VAPID-ключи, не ключи рабочего сайта. Приложение не меняет
Neon и не публикуется автоматически. При работе через HTTPS-прокси проверьте
соответствие исходящего Origin и адреса. Логин для тестовой панели: `owner`.

На iPhone под управлением iOS 16.4+ откройте **тестовую** админку в Safari,
выберите «Поделиться» → «На экран Домой», откройте созданную иконку и войдите.
Разрешите Push, выполните тестовую запись под вымышленным именем и проверьте
уведомление. Откройте клиентский сайт из установленной панели и проверьте, что
админка остаётся доступной, затем протестируйте возврат. Проверьте русский,
азербайджанский и английский языки, мобильную ширину, повторное открытие и
отключение Push. После теста удалите установленную тестовую иконку.

Для фактической публикации тестового процесса нужен отдельный временный HTTPS
хостинг. Он пока не создан: дополнительный постоянно работающий сервис может
потреблять бесплатные часы. Настоящая доставка и поведение iOS не считаются
проверенными до выполнения этого сценария на устройстве.
